# Voitation 0.1.21-preview

- A transcription copied because it lost its input waits until an input becomes active again before showing the fan clipboard preview. It does not pop up immediately.
- Tap the copied-text preview to paste into the active input using the existing guarded paste flow. Nothing pastes automatically. Ordinary clipboard copies do not trigger the popup.
- Number, decimal, signed-number, phone-number and PIN inputs automatically request the typing keyboard, like password and email fields. PIN/password privacy protections remain enabled, and the clipboard preview stays hidden there.
- Retains the polished Sand & Cocoa design, approved V-wave logo and selected Thought Loop artwork.

Install this APK over your existing Voitation installation; no uninstall is needed. Android 8.0 or later. Package `app.voiceflow`, version code 93, original signing identity retained.

Both Android builds/lints, 43 Java suites, durable recovery regressions, native input-type routing, clipboard/privacy/Restore checks, light/dark, 160% text and unfolded layouts passed. The signed application payload matches the native-tested build. Physical-device installation and real cross-app keyboard/focus behavior remain unverified. iOS was not tested or released; backup/OAuth remains paused.
