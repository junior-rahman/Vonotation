# VonoTation

Android dictation, voice notes, translation, and call recording.

Current published baseline: **0.1.7**, version code **79**, package `app.voiceflow`.

This repository hosts the signed APK, the original editable source archive, and `latest.json` for the in-app updater. The 0.1.7 release preserves wireless-debugging pairing across app updates. The earlier audit fixes are in progress and are not claimed as part of 0.1.7.

Signing keys, user API keys, recordings, and account data are not included. Historical documentation inside the original source archive describes earlier builds; `app/build.gradle` identifies the current source version.
