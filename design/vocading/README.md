# Vocading artwork integration

Native vector geometry follows the user-provided **Vocading logo and audio control concepts.png** sheet (Forest & Copper, circular waveform mark). The scalable paths adapt the sheet for native controls and launcher safe areas.

- App/footer: open circular waveform with a copper dot; adaptive and monochrome Android launcher assets.
- Ready, pressed, starting, recording, saving, transcribing, saved, retry, microphone-blocked, disabled, play and pause assets follow the supplied state sheet.
- Voice notes, calls, import, transcript, share, delete, stop and settings follow its feature glyphs. Search, pin and edit use platform controls.
- Labels remain visible and accessible. Icons supplement status text.
- SVG files are the reusable geometry; Android uses VectorDrawables. iOS assets are staged separately on the `improve/vocading-recordings` branch.

Vocading keeps its existing Daybook palette and card layout. Voitation's launcher is unchanged.
