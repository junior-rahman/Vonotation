# VonoTation 0.1.17 (89) iOS Simulator preview

Use the iOS package in **iOS Simulator on a Mac with Xcode**. It is **not an installable iPhone IPA**. For a physical iPhone or iPad, build the included Xcode project using your own Apple development team, signing and provisioning. VonoTation has no Apple ID sign-in requirement inside the app.

The native Daybook includes dictation, Quick thoughts with concise summaries and full transcripts, local source recordings, daily pages, explicit clipboard capture, translation, provider settings and password-encrypted Files backup. Recording keeps its original kind until Finish or Cancel. Full-text disclosure and guarded deletion have native UI regression coverage.

Native verification passed on the exact source commit [`ee43607f4030c94377ecabe06c0d326304e26d04`](https://github.com/junior-rahman/Vonotation/commit/ee43607f4030c94377ecabe06c0d326304e26d04):

- [macOS CI run 38865347766](https://github.com/junior-rahman/Vonotation/actions/runs/38865347766): **40/40 tests on iPhone SE (3rd generation)** and **40/40 on iPad mini (A17 Pro)**, with zero failures or skips.
- Both simulators ran **iOS/iPadOS 26.2, build 23C54, arm64**. Xcode **16.4 (16F6)** used SDK **18.5**. The source deployment target is 17.0; this does not establish iOS 17 hardware testing.
- Unsigned iPhoneOS SDK compilation and the Release Simulator archive passed. One microphone-permission deprecation warning remains.
- Source inventory, artifact hashes, generated recording-intent metadata and ten native screenshots were verified. Screenshot fixtures are isolated Debug data; generated metadata checks do not establish Siri voice recognition or device discovery.

Included: Simulator app ZIP, iOS source ZIP, native verification JSON, screenshots, release provenance and checksums. The existing verified **Android 0.1.17-preview APK and source are included unchanged**.

iOS does not include the Android floating overlay/accessibility insertion, background clipboard collection or other-app call recording. Call audio can be imported from Files. iOS Google Drive linking and Android/iOS backup interchange are not included. Files backups exclude audio, clipboard and API keys. Android Google OAuth registration for the current signing certificate and live Drive connection remain unverified.

Physical iPhone/iPad hardware, real microphone quality and long background recording, live paid providers, user signing/provisioning and App Store/TestFlight distribution remain untested. Private signing keys, credentials and provider API keys are not bundled.
